## 🧮 算法核心

### 格局判定优先级（七层 + 干支作用检测）
```
1. 气势判定 → 三合局改月令本气
2. 从格判定 V3.0 → 藏干印比权重 + 十二长生约束 + 假从阈值收紧
  2.5 干支作用 → 天干冲合检测，用神被克则降格
3. 关键交互 → 伤官合杀 → 食神制杀 → 杀印相生 → 伤官配印
4. 特殊气候格 → 金水伤官/食神、木火通明、水火既济、土金伤官
5. 阳刃 / 建禄 / 月劫
6. 司令真神透干取格
7. 月支本气兜底
```

### 真太阳时校正
```
输入北京时间
  ├─ 经度差: (城市经度 - 120°) × 4 分钟
  ├─ 均时差: 9.87sin(2B) - 7.53cos(B) - 1.5sin(B)
  └─ 夏令时: 1986-1991年4/15-9/15 扣 1 小时
→ 校正后时间 → 影响时柱、月柱（节气边界）
```

### 大运起运计算
```
顺排: 出生日 → 下一个节的天数 ÷ 3 ≈ 起运年龄
逆排: 上一个节 → 出生日的天数 ÷ 3 ≈ 起运年龄
大运: 月柱顺/逆排 8 步，每步 10 年
```

## 🎨 设计理念

本项目秉持 **「传统内核，现代外衣」** 的设计理念：

- **传统内核**：子平命理古法 + 星露实战派经验 + 穷通宝鉴调候体系。含藏干权重、十二长生、干支作用关系
- **现代外衣**：国潮审美设计，响应式布局，3D 翻转卡片，三主题切换
