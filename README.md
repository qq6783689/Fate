## 🚀 快速开始

### 方式一：直接打开
下载 `index.html` 文件，用任意现代浏览器打开即可使用。

```bash
# 克隆仓库
git clone https://github.com/qq6783689/Fate.git

# 直接打开
cd Fate && open index.html
```

### 方式二：本地服务器 (推荐)
```bash
# 使用 Python
python3 -m http.server 8080

# 或使用 Node
npx serve .

# 浏览器访问
open http://localhost:8080
```

## 🧮 算法核心

### 格局判定优先级
```
1. 真假从格判定 (日主无根先查从格)
   ├─ 真从财格 / 假从财格
   ├─ 真从杀格 / 假从杀格
   └─ 真从儿格 / 假从儿格

2. 关键交互优先 (Interaction Priority)
   ├─ 伤官合杀
   ├─ 食神制杀
   ├─ 杀印相生
   └─ 伤官配印

3. 特殊气候格 (Climate Special)
   ├─ 金水伤官 / 金水食神
   └─ 木火通明

4. 阳刃 / 建禄 / 月劫

5. 普通正格判定
```

### 调候激活机制
```
冬金遇火 → 寒金得火炼，名利双收 ✅
夏木得水 → 焦木逢甘霖，枯木逢春 ✅
冬土暖局 → 冻土得阳和，万物生发 ✅
```

## 🎨 设计理念

本项目秉持 **「传统内核，现代外衣」** 的设计理念：

- **传统内核**：严格遵循子平命理古法，30+ 种格局判定，真假从格区分，调候体系完整
- **现代外衣**：国潮审美设计，响应式布局，流畅的交互动画，现代化用户体验
- **人文关怀**：避免宿命论，强调主观能动性，给出积极正向的人生指引
