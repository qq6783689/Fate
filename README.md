## 🧮 算法核心

### 格局判定优先级（八层 + 干支作用检测）
```
1. 气势判定 → 三合局改月令本气
2. 从格判定 V3.1 → 藏干印比权重(本/中/余气) + stemsExclDM 排除日主 + 十二长生约束
  2.5 干支作用 → 天干冲合检测，用神被克则降格
3. 关键交互 → 伤官合杀/食神制杀/杀印相生/伤官配印/伤官生财/食神生财
3.5 化气格检测 → 天干五合 + 月令支持化神（传统外格）
4. 特殊气候格 → 金水伤官/食神、木火通明、水火既济、土金伤官
5. 阳刃 / 建禄 / 月劫
6. 司令真神透干取格
7. 月支本气兜底
```

### 真太阳时校正
```
输入北京时间
  ├─ 经度差: (城市经度 - 120°) × 4 分钟
  ├─ 均时差: 9.87sin(2B) - 7.53cos(B) - 1.5sin(B)
  └─ 夏令时: 1986-1991年4/15-9/15 扣 1 小时
→ 校正后时间 → 影响时柱、月柱（节气边界）
```

### 大运评分体系（七层 + 五档制）
```
L1 十神本性   ±0.5~1  (原局已有则减半)
L2 冲合反应   合绊±1 / 合化±2~3 / 争合0 / 冲±1~3 (有根则抗)
             地支半合+1(喜忌翻转) / 六合+0.3 / 冲-0.5
L3 制化关系   +1
L4 十二长生   临旺+1 (天干无力不扣)
L5 调候贡献   +0.3~1 (地支藏干+0.3)
L6 格局喜忌   天干±1 + 地支本气±0.3
L7 病药检测   ±1.5 (大运是否解原局之病)
---
五档判定: ★★大吉(≥3) ★小吉(≥1) ◎平运 ☆小凶(≤-1) ☆☆大凶(≤-3)
走势总览: 七种趋势类型 + 前半/后半生对比
```

### 大运起运计算
```
顺排: 出生日 → 下一个节的天数 ÷ 3 ≈ 起运年龄
逆排: 上一个节 → 出生日的天数 ÷ 3 ≈ 起运年龄
大运: 月柱顺/逆排 8 步，每步 10 年
```

## 🎨 设计理念

本项目秉持 **「传统内核，现代外衣」** 的设计理念：

- **传统内核**：子平命理古法 + 穷通宝鉴调候体系。含藏干权重、十二长生、干支作用关系
- **现代外衣**：国潮审美设计，响应式布局，3D 翻转卡片，三主题切换
- **人文关怀**：避免宿命论，大运文案按年龄分5档（少年/青年/壮年/中年/晚年），给出贴合人生阶段的积极指引
